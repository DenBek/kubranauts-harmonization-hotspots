A calendar of burning activity

Pick a region and read the season against its own history. The figures are harmonized cell-days: a grid cell counted as burning on one day, after MODIS and VIIRS have been put on one scale. Raw hotspot counts from the two sensors are not comparable, which is why the calendar uses this unit. Every term is defined under Terms.

Sample numbers, for now

The pages read illustrative cell-days so the layout can be tried before the gold tables are in the bucket. The banner says so. These figures are not FIRMS detections, and the map dots are not observed burn scars.

When a gold table is ready

  1. Write the Parquet to gold/<table>.parquet in the firms-data bucket. The six names are listed in WEB_DEPLOYMENT.md.
  2. In the Codespace, run python scripts/export_calendar.py. It writes publish/<table>.json for each file it finds.
  3. Reload this site. A table that was exported leaves the sample. The others stay on the sample, and each banner says which.
