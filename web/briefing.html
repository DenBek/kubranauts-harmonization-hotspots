Where a live send would be turned on

Leave these unset for the demo. When you want a real text, add them on the Cloudflare Pages project under Settings, Environment variables, Production, then redeploy:

  • TWILIO_ACCOUNT_SID
  • TWILIO_AUTH_TOKEN
  • TWILIO_FROM
  • TWILIO_LIVE set to true

The function in functions/api/notify.js still does not call Twilio. The send has a marked spot in that file, and it stays off while TWILIO_LIVE is unset. Do not commit these values. They are Pages settings, separate from the Codespaces secrets.
