Where a live send is turned on

Add these as secrets on the Cloudflare Pages project (Settings, Variables and Secrets) on Production and Preview, then redeploy:

  • TWILIO_ACCOUNT_SID
  • TWILIO_AUTH_TOKEN
  • TWILIO_FROM
  • TWILIO_RECIPIENTS as Name=+1…,Name=+1…
  • TWILIO_LIVE set to true

The map's Send this briefing to a phone box sends through functions/api/notify.js, only to the names in TWILIO_RECIPIENTS. This page's preview never sends. Do not commit these values. They are Pages settings, separate from the Codespaces secrets.
